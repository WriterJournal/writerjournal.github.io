Lost data

Although rare, there might be times when user may experience data lost, either due to human error or device malfunction. In this section, we will talk about lost data recovery in details.

First of all, user needs to know if it’s only some documents getting corrupted or it’s a complete data lost. Followings are characteristics for both:

Corrupted document: it may happen when the device is in power saving mode and user switching between multiple apps, the Android OS tend to kill any background app which consumes power during this process, it’s recommended to exclude Writer Journal from power saving mode to prevent corrupting documents. The typical characteristic of a corrupted document is that the document can still be viewed in the listings but when it’s loaded into the editor page, its content becomes empty although its size is not zero.

Complete data lost: When user experience complete data lost, user will find all of their documents are completed gone, not present in the documents page, nor in the recovery zone. This may happen when user reinstalls the app without specifying the Home Folder he used before, or the device has been factory reset etc.

How to recover a corrupted document:

To recover a corruped document, user will need to enable a special page called “Dev tool”, Go to the Settings page -> App Settings -> Dev tool. (Enable it)

Before recovery process, we strongly suggest that a manual data backup must be performed in case any further data lose happens during the recovery process.

  1. After enabling the “Dev tool” page, please open the side navigation menu and select “Dev tool”.
  2. In the Dev tool page, select “Fix corrupted document”, user will be presented with 4 options.

We recommend user to to select the “Diagnose” option firstly, user can send us back the diagnose result through email so that our support team can identify the underlining problems with the document.

Auto fix: as the name suggests this option will try to auto fix the document by itself.

Rollback to latest valid version: This option will rollback the selected document to its most recent working version. (might erase the most recent changes to the document!)

Recover to plaintext: This option will remove all the formatting styles and images from the corrupted document, leaving only the plain text. (This option will work most of the time, but be aware that all the formatting styles and images will be lost permanantly)

  1. After selecting one of the 4 options, user will have to select a corrupted document to start the process.

How to recover a complete data lost:

Although such an event is extremely rare, users may lose their entire data out of accident, like damage to their device, or forget to enable Auto backup schedule. Followings are specific steps to recover any lost data.

If your entire documents and folders are gone for any unexpected reason, there are 3 ways to recover your data in WriterJournal app.

1.If you had backed up your data through manual backup mechanism before your data got deleted, you can manually restore your data by navigating to: Side Navigation menu -> Data backup -> Under Manual Backup tab -> Select Restore Data-> Select “OK” -> Find and select your backed up data file (WriterJournal data backup file has .wjb file extenstion)


2.If you have never backed up your data manually, or your manually backed up file is too old and doesn’t contain the desired content, your second option will be Auto backup schedule. If you had selected a “Home Folder” for WriterJournal to use when you first launch the app, Auto Backup schedule will be automatically enabled for you, otherwise, you will have to manually enable it in the Settings page or under the Auto Backup Tab in the Data backup page. If you had enabled Auto backup Schedule before your data got deleted, you can recover your older backup files in the Auto backup page. Make sure to recover to the latest uncorrupted backup file so that you can recover most of your writings.


3.If you have neither manually backed up your data nor enabled auto backup schedule before your data got deleted, WriterJournal offers you a last option to recover your data, that’s called Emergency Backup Mechanism, If your auto backup schedule is off, WriterJournal will automatically enable Emergency Backup Mechanism to periodically back up your data at the following location:

Storage/Download/WriterJournal/EmergencyBackup/

All you need to do is navigating to Data backup page -> Under Manual Tab -> Select Restore -> Click “OK” -> Select a latest or a backup file that contains your desired content at that location. (Search In the EmergencyBackup folder)


I changed my device, how can I move my data from my previous device to the new device?

All you need to do is to get the latest WriterJournal backup file, and transfer it to your new device. There are 2 ways to do that:

  1. By using the Google Drive Space (If you don’t have Google Drive, you can jump right into the second option). On your old device, launch WJ and navigate to Data Backup page -> Under Manual Tab -> Select “Backup Data” -> Select “Backup data to Google Drive” -> Select your desired folder -> Name your backup file or leave it as default -> Select “Save”.

Now you have successfully backed up your entire data and exported the backup file to your selected folder. Now, on your new device, launch WJ and navigate to Data Backup page -> Under Manual Tab -> Select “Restore Data” -> Select “OK” -> Select “Restore data from Google Drive” -> Select the backup file you exported in the previous steps -> Wait until it completes.

Congratulations, you have successfully transferred your data from your previous device to your new device. (See the screenshots)


  1. By manually transferring the backup file to your new device, On your old device, launch WJ and navigate to Data Backup page -> Under Manual Tab -> Select “Backup Data” -> Select “Backup data” -> Select your desired folder -> Name your backup file or leave it as default -> Select “Save”.

Now you have successfully backed up your entire data and exported the backup file to your selected folder. All you need to do is to manually transfer this backup.wjb file to your new device by any means available to you. After you have transferred this backup file to your new device, launch WJ on your new device and navigate to Data Backup page -> Under Manual Tab -> Select “Restore Data” -> Select “OK” -> Select “Restore data” -> Select the backup file you transferred from your previous device in the previous steps -> Wait until it completes.

Congratulations, you have successfully transferred your data from your previous device to your new device. (If you had uninstalled the app from your older device before transferring the data, please go to the section named “I lost all of my data, what should I do, please help!”)
